# 三维鞋履试穿：两双原创完整鞋与固定足部适配

核查日期：2026-10-06。C18 为三维试衣间增加 Court 低帮鞋和 Ridge 短靴。真实鼠标取放的是完整左右鞋对，穿上后在同一完整人体的脚上显示独立三维鞋；几何、姿态注册、材质和交互由本项目本地实现，没有外部图片试穿、模型推理或远程鞋资产。

## 原人体和原创鞋的范围

完整人体沿用 C17 已保留的 [Quaternius 官方 Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) mannequin，原许可为 CC0 1.0。本轮只读取既有完整原包、原 GLB 与冻结运行人体；没有减面、截足、替换人体或隐藏身体面。冻结 `avatar.glb`、`core-tee.glb`、`field-jacket.glb` 的 SHA-256 均逐字节未变。原人体仍包含全部 53 骨和 13,743 个唯一三角面，脚掌、脚趾、脚踝继续参与实际渲染。

所有鞋网格和替换 PBR 材质均在本地 Blender 5.2.2 LTS 原创制作，未借用另一个鞋模型，也没有真实品牌图案。可编辑 `atelier-footwear-complete.blend` 包含两双完整鞋与完整原人体作适配参照，制作、足部检查、渲染复审和来源登记配方保存在 `assets/fitting-footwear-source-archives/`，位于 web 发布目录之外。原人体完整素材仍保留在 `assets/diver-source-archives/original/`，没有修改。

鞋面外壳使用本地绘制的连续曲面，是真实独立拓扑与薄厚，鞋口为几何开孔，短靴帮为开放的完整筒状鞋片。鞋头、侧片、后跟片、鞋舌、线迹、鞋带和鞋眼均独立建模；分层沿曲面法线放置，避免共面和鞋带埋入鞋舌。不是给原脚改颜色，也不是实心大盒。鞋底为闭合圆角结构；侧壁沟槽可观察，橡胶块几何位于固定平底结构内，不能由此推导真实抓地力或减震表现。

## 接入与有限姿态

人体维持 **1.78 个虚拟参考单位高**，脚底 `Y=0`，`+Y` 向上，`+Z` 为鞋尖和人物正面。鞋对根节点为 `[0,0,0]`、外层比例 1；直接将 `court.glb` 或 `ridge.glb` 的 `gltf.scene` 挂在原人物同一根节点，不能按新包围盒重新居中或改尺寸。

原足关节锚点约为左 `[.086629,.100488,-.034846]`、右 `[-.086629,.100488,-.034846]`。原人体在 `Fitting_Neutral` / `Fitting_Reach` 两个固定登记姿态中双脚保持不动，所以完整鞋对采用刚性注册，无重复 53 骨骨架和鞋动画。人体、原有衣服继续选择同名 clip 并 `setTime(0)`；鞋对不需要 mixer。

这只能验证固定虚拟参考人体的鞋取放、替换、换色、足部对齐、前侧后与细节观察。没有任意体型、现实鞋码、步态、足部扫描或动态鞋面模拟，也没有抬脚或抬高人体来模拟现实鞋底厚度。

## 最终核查事实

入口：`node projects/011-solaris/scripts/verify-footwear-assets.mjs`。最终 **9 项检查通过，状态 `passed-with-finite-foot-domain`**，含原资产冻结 SHA、完整原人体、独立 packed 蒙皮足位、左右独立鞋结构、材质、注册与落地、有限足部包覆、短靴帮包覆、闭合鞋底和来源哈希检查。几何阶段的 8 项实际输出保存在 `finite-foot-verification.json`，第 9 项为最终 manifest 大小与 SHA 核对。

独立解析最终原人体的骨节索引、权重、逆绑定和两个固定 clip，按真实 packed 蒙皮计算足部点：选取 `Y<.155` 的所有原人体足 / 低踝唯一点，共 **264 点**，两种姿态对应点距离小于 `2e-6`。每双鞋的 264 点地面投影全部落入闭合鞋底覆盖区域；鞋底最低点为 `Y=0`，原脚最低点也为 `Y≈0`。

其中 **120 点**在真实椭圆踝口域之外，向上射线均与独立鞋壳相交；**144 点**在踝口投影域内，明确属于开放域，不要求把踝口盖上，未把该域伪称完整外壳封闭。登记踝口中心 `Z=-.034`、X 半径 `.050`、Z 半径 `.059`，左右中心 X 为 `±.086629`。Ridge 的原小腿点另在高度 `[.155,.284]` 采样；除原顶点之外，对跨越该高度域的完整原人体三角面作八阶重心采样，**2,830 点**全部位于短靴帮限定高度的径向外壳覆盖范围内。报告保留实际计数、包围盒和失败数组，没有静默丢弃失败点。

鞋底拓扑按最终 GLB 实际三角形的坐标边独立核查，每条边被两个三角形使用，左右鞋底为闭合结构。该验证说明有限采样外部包覆与接地，不能证明完整体积无交叉、脚与鞋底内部有足够缓冲空腔、生产鞋楦准确性或所有连续动作无穿模。由于人物脚底固定在零高，展示的是注册的外包围鞋壳，而不是现实足底厚度和人体高度改变的物理模拟。

两双鞋 × 两姿态 × 前、侧、背、细节共 **16 张真实完整原人体复审图**，加 **2 张实际足底视图**，共 18 张保存在源档；足底复审只隐藏渲染地面，不隐藏任何原人体面。复审未见明显脚掌从外底漏出。产品网页的实际鼠标穿换、撤销恢复、保存恢复与镜头品质由产品工作区独立验收；资产检查不替代这些交互验收。

运行目录仅发布两个 GLB、有限适配登记、CC0 原许可副本和 manifest 共 5 个文件。原包、完整编辑模型、配方、复审图片和检查记录均在 web 之外。manifest 登记原人体来源与本地原创范围，并逐个记录运行资产、原件、配方和实际复审图的大小与 SHA-256。
