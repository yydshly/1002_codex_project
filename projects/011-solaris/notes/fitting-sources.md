# 三维试衣间：人体、服装与有限适配范围

核查日期：2026-10-05。页面在本地加载完整人体和两款独立三维服装，并由本项目控制鼠标取衣、穿上、换色、观察和姿态选择。没有使用外部模型推理、图片试穿或动作后台。

## 完整原人体

采用 [Quaternius 官方 Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) 的完整 `Mannequin` 与 53 骨骨架。作者在 [OpenGameArt 的原始发布](https://opengameart.org/content/universal-animation-library) 提供 Standard 原包，网页与包内 `License.txt` 标注 CC0 1.0。已经保存的 14,541,205 字节原 ZIP、完整解压包和 6,671,104 字节原 GLB 继续位于 `assets/diver-source-archives/original/`；本轮只读取这些原件，没有修改之前的水下素材或存档。

原模型有 13,744 个索引三角形，其中一面完全重复。Blender 自动去重后，全部 13,743 个唯一人体面和完整上下肢、手指、膝、踝、脚趾均保留，没有减面、截断、基础几何替身或身体隐藏遮罩。制作脚本在导出前逐顶点、逐面断言原人体网格未变。输出分成两个材质区，所以导出的顶点列表会为材质边界拆点；GLB 导出也可能烘焙绑定变换，不能把导出后的数组顺序称原包逐字节相同。

这是风格化、无五官的完整展示 mannequin。替换材质把上身和裸露四肢表现为暖灰色，下半身表现为深墨色整体基体；这不构成第三款可试穿裤子或鞋。人体统一归一到 **1.78 个虚拟参考单位高**，脚底在 `Y=0`，人物面向 `+Z`。该身高只定义固定展示基体，不从真人照片测量，也不推断现实衣服尺码。

## 原创独立服装

使用本地 Blender 5.2.2 LTS 制作。可编辑文件 `assets/fitting-source-archives/atelier-fitting-complete.blend`、完整制作配方 `build_fitting.py`、来源登记配方和前背侧模型复审图片均在发布目录外。运行目录只存导出的模型、来源登记、原许可副本和固定适配登记。

| 登记款 | 新建几何与观察位置 |
| --- | --- |
| `tee-01` / Core Tee | 完整宽圆领短袖上衣；连续躯干、肩部、腋下和左右袖片，真实开口与厚度，独立曲面胸袋、袋口线迹、肩缝和领袖下摆滚边 |
| `jacket-01` / Field Jacket | 完整长袖轻夹克；连续肩袖，宽圆口与包边、袖口、下摆，独立中央门襟、拉链齿和拉头、两曲面胸袋及盖片、两斜插袋口、侧缝与背部育克；没有宣称真实立领 |

服装没有使用外部衣服模型，也不是改变人体颜色来表示穿上。躯干、圆肩和渐变袖管来自本地绘制的连续轮廓；融合为独立拓扑，平滑后真实裁开袖口、下摆与颈口，再加入 `0.0022` 源单位的实体薄厚。配方记录的尺寸只用于这个固定 mannequin。它没有真人扫描、裁片展开、生产纸样或定制尺码准确性承诺。

连续衣片按原骨架的真实胸椎、髋与肩部编排平滑权重，并与邻近原上臂/前臂的完整源权重融合；衣片与人体在独立 GLB 中共享同名 53 骨及兼容逆绑定矩阵，独立核对矩阵元素差异小于 `2e-6`。衣服的当前姿态由这些骨节变化实现，不通过更换一张图片实现。全部人体持续参与渲染，没有隐藏肢体来回避穿模。

主布材质为 `Fitting_Fabric`，页面登记的 ivory / moss / ink 配色只替换主布。`Fitting_Trim`、`Fitting_Stitch`、`Fitting_Hardware` 独立表示边口、线迹与金属；大幅换色仍可近看袋口、拉链和背部结构。全部模型为内嵌 GLB，不发出远程模型、材质或纹理请求。

## 两个固定登记姿态

`Fitting_Neutral` 与 `Fitting_Reach` 是本地编排的两种固定姿态，分别表示自然站姿与有限侧向举臂检查。每种完整保留 53 骨的 159 条位置、旋转、比例通道，所有通道在两秒内恒定；双腿与脚底保持不动。它们用于比较相同衣服的肩、袖、腋下和下摆适配，不是任意动作、人体 IK 或连续布料运动。

接入时将 `avatar.glb` 与选中的 `core-tee.glb` 或 `field-jacket.glb` 原样挂在同一个外层根节点，外层比例保持 1。选相同 clip，再对各自 mixer 调用 `setTime(0)`；无需每帧重新取包围盒中心。资产默认节点写入自然站姿，所以尚未启动 mixer 时也能正确观察。独立陈列架上的服装保持自然站姿；人物穿着的衣服随所选人物姿态变化。

这是确定性姿态选择：状态只需要保存 neutral / reach，而不需要保存动画时间。照片导出记录当前实际三维形状；网页保存恢复仍由独立交互工作区验收，不由资产检查替代。
