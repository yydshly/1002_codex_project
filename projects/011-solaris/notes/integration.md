## 整套备份与选择恢复（0.17.0）

在[精选陈列](http://localhost:4189/projects/011-solaris/collection.html)点击“整套工作台备份”。这项支撑让一次跨场景工作的成果可以共同保留，再按工作台选择恢复；它深化既有工作流，不新增研究能力或场景。

先在各工作台完成操作、保存并关闭其他编辑窗口，再回陈列读取本机存档。一份文件含陈列、客厅、展厅、影像、地标、料理、创作、滑板、材料、水下十个固定记录，保存最近已持久化的原文，不触发目标页保存或中断动作。未保存编辑不在这份文件中；下载文件上限12MiB。

整套文件协议为atelier-workspace/version 1，records固定十项，每项保存原文字符串或null。仅有旧水下v1时，应提示先到水下保存升级；它不被说成“没有存档”，旧key和返回检查点只作并发检查基线，不写入整套文件。旧原文继续保留。

通过实际文件选择器打开整套文件，或点击“查看备份内容 / 粘贴已有备份”读取完整JSON、复制或粘贴后检查；这些操作不立即写入。表格展示文件内容、本机差异与可恢复状态；勾选有效工作台，先下载恢复前的本机备份，再明确点击“恢复所选工作台”。未勾选和文件空项保持本机；恢复后重新打开对应工作台，由各页重建稳定方案。读取最新陈列会清空本窗口预览及撤销历史。

| 文件或本机状态 | 应显示的说明与处理 |
| --- | --- |
| 有效记录与本机不同 | 展示差异，用户明确选中后才覆盖对应存档 |
| 有效记录与本机相同 | 说明内容相同，不冒称生成新方案或新增编辑 |
| 文件中没有保存该工作台 | 明确“未保存”，不删除本机，也不制造初始方案充当备份 |
| 原文无法解析或业务结构不合法 | 原样保留供抢救；该项禁恢复，不用默认方案掩盖坏记录 |
| 文件格式、版本、大小或固定记录结构不支持 | 明确拒绝整份文件；预览检查不写入 |
| 检查后本机记录被其他窗口更新 | 暂停恢复并要求重新读取/检查，保留文件与原记录 |
| 恢复写入失败或回滚受阻 | 按实际结果说明失败、恢复或较新记录保留，不笼统宣布全部成功 |

**稳定存档范围：** 陈列保留顺序、锁定、详情选择、选品、偏好和最近去向；客厅保留当前project、个人挂画与完整A/B project/thumbnail/date；展厅和地标保留外观、观察及相机配置；影像保留每张登记原片的视口、校准和测量；料理保留稳定食材实例、姿态、编号和相机；创作保留正式来源选区、完整图层、笔触及压力；滑板保留已落地的试验账与选中记录；材料保留样品热量和完整热账；水下保留鱼/潜水员位置、方向、路径账与相机。

文件不包含会话撤销、未提交预览、进行中的动作/供热/追随、返回检查点或试衣/真人任务。模型、纹理、渲染依赖和真人权重仍由本地项目提供，备份文件不是独立可运行产品；个人挂画与A/B缩略图属于文件内容。影像在不同视口重开会调整显示偏移，应分别判断方案数据保持和视口适配。

恢复前须保存并关闭其他编辑页，恢复后重新打开。现有目标页没有统一的多窗口同步保护；原文比较和受控回滚不等于十记录原子事务，也不保证同时写入不会冲突。

**本轮实际验收：** 内置浏览器公开导出显示10/10有效保存，已读取完整文本框JSON。通过实际文件选择器打开同一导出内容生成的JSON，十项与本机相同且应用禁用。另一实际文件仅将陈列选品加入阅读灯、展厅车漆改pearl；地标坏原文和料理null均禁恢复。明确恢复两项后仅陈列/展厅原文改变，其余八份逐字保持；粘贴原整套JSON恢复后全部十份逐字回到基线。再取消展厅勾选只恢复陈列，展厅保持；另一窗口移除临时灯后，旧预览应用禁用且旧的恢复前备份链接撤销，读取最新后十份原文仍与原基线一致。{}坏外层文件明确拒绝，不显示可恢复条目；核查后用户原陈列保持。

整套备份接入使用 `createWorkspaceBackup(storage)`：`capture()`只读汇总，`preview(text)`校验文件并登记当前基线，`apply(selectedIds)`只应用已预览且明确选中的有效差异项。界面按需加载，不启动九个渲染器；写入成功后陈列读取自己的新记录，其余工作台须关闭旧页后重开。此接口不提供跨设备同步或十记录原子事务。

基本调用如下。所有修改放进 `History` 事务，再同步渲染与界面。导入项目先校验。

```js
import {
  History, initialProject, validateProject, updateObject,
  resizeObject, duplicateObject, removeObject, restoreObject, replaceTable
} from './studio/core.js';
import { createStudio } from './studio/scene.js';

const history = new History(initialProject());
const studio = await createStudio(document.querySelector('#canvas-host'));
let copyId;
history.run('复制阅读椅', project => { copyId = duplicateObject(project, 'chair'); });
history.run('调整高度', project => {
  const result = resizeObject(project, copyId, 'y', 1.35);
  if (result.blocked) throw Error('尺寸与其他家具冲突');
});
history.run('更换茶几', project => replaceTable(project, 'table', 'solid'));
studio.apply(history.current);
studio.select(copyId);
// 输入来自 JSON 文件时：history.replace(validateProject(input.project))。
// 失败的 History.run 会回滚部分修改；撤销/重做后再次 studio.apply。
```

`updateObject` / `resizeObject` 返回 `{ changed, blocked }`；空间占用时对象不改变。房间边界夹紧与轴比例限幅会产生合法的实际尺寸，界面重新显示实际值。`duplicateObject` 返回新 ID；`removeObject` 返回移除的组合 ID；`restoreObject`、`replaceTable` 在无法完成时抛出错误。调用方使用事务统一处理回滚和反馈。

场景采用米制、Y向上；旋转为弧度。地面对象以底部锚点落地；挂画中心贴固定墙面；台灯 X/Z 是父茶几未拉伸的局部坐标，世界位置组合父级旋转、整体比例和各轴尺寸，Y为实际桌面高度。台灯自身尺寸独立。型号替换后的宽深高来自校准模型，不沿用旧模型的包围盒。

## 影像工作台接入与验证目标

页面 `web/imaging.html` 用真实高清 X-ray 图片验证同一鼠标轨迹在不同工具中如何改变含义：平移移动视口，缩放改变以指针为锚点的显示比例，测量则创建原图坐标标注。实现采用自有二维坐标工具与本地画布，不使用外部模型，也不改写源 JPEG。亮度、对比度与反相属于显示调整，不是基于原始 DICOM 数据的窗宽窗位。

`web/imaging/app.js` 直接通过 Canvas 绘制并处理工具、标注、面板与存储；不额外依赖影像或图形处理库。固定两张源图，不支持上传与 DICOM 导入。亮度面板为 −80%–100%，对比度为 0.25–4×。浏览器存储键为 `atelier-imaging-workspace-v1`，每张图使用独立 40 条历史和独立校准/测量状态；模式切换、Escape 或失去输入会取消未完成手势。

| 验证能力 | 用户操作 | 可检查的结果 | 范围与验收边界 |
| --- | --- | --- | --- |
| C22 图像视口与工具语义 | 平移拖动、缩放拖动、滚轮、适应画面与 1:1 | 指针下图像点在缩放时保持锚定；工具模式决定同一路径的作用 | 二维本地 JPEG；不补全、生成或解释图像内容 |
| C23 图像坐标测量 | 拖动绘制线、拖动端点，之后放大和平移 | 同一标注保留原图坐标，像素长度不随视口变化；端点编辑改变对应长度 | 默认 `px`；没有可靠 PixelSpacing，不能把样例长度直接当作毫米 |

### 图像状态与算法接口

`web/imaging/core.js` 提供 `initialState`、`validateState`、`imageToScreen`、`screenToImage`、`fitView`、`zoomAt`、`panView`、`imagePoint`、`measurementLength`、`calibrate`、`moveEndpoint` 和 `History`。schema `version: 1` 保存图像 ID 与尺寸、显示变换、亮度/对比/反相、参考校准及测量端点；备份不携带远程图像 URL。

显示关系为 `screen = image * scale + offset`；指针位置用逆变换还原原图坐标。两点长度由原图坐标计算，校准后乘以 `lengthMm / referencePixelLength`。缩放限制为 4%–1600%，最多 100 条测量线，历史保留会话内最近 40 条；参考线至少 1 像素，参考长度允许 0.01–1,000,000 mm。配置拒绝未知字段、非有限数值、越界端点、重复测量编号和不支持版本；编辑异常回滚。

备份封装为 `{ format: "atelier-imaging", version: 1, activeId, viewport: { width, height }, states: { hand, "chest-lateral" } }`。复制/粘贴导入上限 64 KiB，严格匹配两张登记图的编号和尺寸；导入不携带原图或远程 URL，恢复时重新加载本地原片。影像配置不能当作客厅或汽车配置导入。

```js
import { History, initialState, zoomAt, measurementLength, calibrate } from './imaging/core.js';

const history = new History(initialState(1466, 2082, 'hand'));
history.edit('放大到指针', state => {
  state.view = zoomAt(state.view, { x: 300, y: 200 }, 1.25);
});
// 测量 a/b 必须来自 screenToImage/imagePoint，不能保存屏幕坐标。
const length = measurementLength(history.current, {
  a: { x: 200, y: 300 }, b: { x: 500, y: 700 },
}); // 未校准：{ value: 500, unit: 'px' }
// 只有用户提供可信已知长度时才调用 calibrate，不能推断图片物理尺度。
```

两张原始图片均由 Mikael Häggström 以 CC0 1.0 公开：手部 1466×2082、胸部侧位 1769×2453。源 JPEG 未作本地裁剪、绘制标尺或 AI 修改；未见患者姓名/编号，来源、许可、文件哈希及核查范围见 [素材说明](imaging-sources.md)、[本地清单](../web/assets/imaging/manifest.json) 与 [归属](../web/assets/imaging/credits.md)。没有可核实 DICOM PixelSpacing，默认 `pixelSpacing: null`；JPEG DPI 不得用于转换物理单位。

素材完整性已有独立脚本校验；功能状态测试与浏览器验收由主任务写入 [验收记录](product-validation.json)。此接入说明列出应验证的能力，不预先宣称浏览器操作已经通过。

### 状态、规则与安全返回

状态schema v1固定保存version/order/pinned/selected/wishlist/preference/lastScene。order始终为六个登记ID的完整排列，双端锁定时交换拒绝；有效鼠标交换会选择所拖物品为详情。收藏wishlist与详情selected不是订单状态。四偏好all/reading/compact/natural使用作者标签固定权重，只排序未锁槽位，同分保持当前相对顺序；all保留当前顺序。40条会话历史、完整动作一条事务，本机键为atelier-collection-workspace-v1，JSON输入上限64KiB；重开不恢复整段撤销历史。

有限去向由六场景字典与中文前缀/别名匹配，不接受任意URL或多目标指令。确认进入前保存严格version/token/sceneId/shop检查点，使用atelier-collection-trip-v1；token为16位小写hex，目标URL限定登记相对页面并附from=collection与trip。旧六页面的[只读桥](../web/collection/scene-return.js)严格检查存储、token、sceneId及同源pathname，才显示固定collection.html?resume返回链接；桥不修改旧工作台状态或存储。返回恢复选品主字段，最近场景lastScene有意更新为所访问场景。当前行程匹配依本机检查点，不声明额外的时间到期机制。

状态/规则由[core.js](../web/collection/core.js)，鼠标事务/预览/保存/进入恢复由[app.js](../web/collection/app.js)，完整本地PBR摄影由[render-products.js](../web/collection/render-products.js)实现。六素材读取既有资产清单，无新增下载或外部模型服务；输入与存储失败保护应单独做实际故障验收。

### 主流程验收与专项

铜铝Cp由NIST固相Shomate式在298.15K计算，25–60°C以常数作教学近似；冰潜热依据Harvey2019。铜铝的质量/初温相同，冰为不同质量和起温，不能称三个相同初始条件实验，也不能用三个不同终点耗时证明某材料普遍更快。[物性与来源](materials-sources.md)和[参数/假设](../web/materials/reference-data.json)保留单位、原方程依据和边界。

输入假设为已吸收10W均匀功率、零散热；Q=Pt、金属ΔT=Q/(mCp)、冰液相分数=Q/(mLf)。0.10.0采用教学时钟×4，独立核查保留该次换算，物理核心功率仍10W。一次定长试验显示13.1852教学秒，但UI操作窗约3610ms，不把自动化动作窗当作精确外部时间基准。移开只停止能量输入，不预测冷却或结冰；金属60°C为教学上限，不是熔点，冰融尽不继续热水/沸腾。
