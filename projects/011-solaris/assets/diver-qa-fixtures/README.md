# 潜水员备份 UI 测试夹具

本目录位于 web 外，只供测试人员通过网页“备份 / 打开位置”粘贴 JSON，验证导入、原子拒绝、40 条容量保护、编号保护和旧版安全初始化迁移。程序生成的 40 条联动记录不能称为 40 次真实鼠标操作验收；每条鱼段扫掠保护和有限速度潜水员轨迹都通过现有 API 验证。

五个 valid 文件通过对应版本严格 validate 和 JSON 回读；五个 invalid 文件都被 schema 2 兼容解析器按预期拒绝，拒绝原因见 manifest.json。坏文件导入后应保持原工作区、记录、鱼和潜水员不变。

合法 v1 文件保留一条从 INITIAL_FISH 到 INITIAL_DIVER.position 的旧鱼记录。固定 x=-1.85 的路径通过旧 core 礁石/水域扫掠检查；文件无潜水员字段或潜水员历史。迁移后当前鱼位置及原鱼 ledger 必须保留，潜水员须选择安全初始化站位，旧行均标记 legacy，不能伪造过去跟随。

另一个 invalid-v1-fish-at-diver-without-ledger.json 故意去掉旧鱼记录。旧 schema 1 要求空 ledger 的鱼处于 INITIAL_FISH，所以此文件必须拒绝；它不是合法迁移样例。

导入合法夹具前先保留真实工作区备份。容量和编号文件仅供保护条件验证；完成后恢复原工作区。本轮未再次执行全量产品 suite。
