后续规划 · 尚未接入

当前已接入的是照片输入、本机生成、鼠标对照与人工评审。以下是可以继续研发的产品方向；本场景先保留研究成果，暂缓扩展，项目继续推进其他能力。

01 / 优先方向

真实商品选款导购

为门店导购、品牌客服和顾客比较几款真实衣服，保存候选清单，再查看商品或交给导购。

需要补充真实商品编号（SKU）、颜色款、价格、库存与购买链接；原商品图始终可见，方便核对生成图有没有改错衣服。

02 / 提案与沟通

造型师提案工具

为同一客户比较几个衣款，标注选择理由，把方案交给客户讨论。

需要补充客户档案、方案保存、批量生成与批注。完整套装、多件搭配需要另行开发。

03 / 实拍前筛选

品牌视觉预演

在正式拍摄前，初步筛选模特、衣款和构图，减少方案沟通的成本。

需要补充授权模特与商品素材、批量处理和商品细节审核；生成预演不能替代商品实拍证据。

04 / 衣物管理

个人数字衣橱

把已有衣物与待购商品放进同一清单，辅助日常搭配与采购规划。

需要补充衣物归档、多件搭配、下装与鞋履，以及个人照片和衣物数据的保存管理。

05 / 独立研发模块

尺码与合身推荐

根据人体和商品的真实数据，辅助选择尺码，与外观预览一起使用。

需要补充人体测量、每款服装实测尺寸和实际试穿反馈。现有生成图片不能推导这些结论；布料模拟另需纸样与面料参数。

PROPOSED FIRST PILOT

先做一个品牌，10–20 款授权上装。

这是建议的下一轮试点范围，尚未建立真实商品目录。用户选择三款上装，生成后并排比较，放大查看领口和图案，圈出问题、排序收藏，最后保存带真实商品信息的候选清单。

鼠标交互服务于选款、核对和沟通。是否有价值，要看用户是否更容易作出选择，以及生成图是否保留同一件商品的关键细节。

继续前需要验证

  • 商品保真：采集人物原照片、目标商品图、同人实际穿着图三方对照，记录衣款、图案、身体与遮挡偏差。
  • 选款价值：记录无指导完成率、衣款辨认、候选缩小情况和等待时间；失败次数及误把生成图当实拍的情况一并记录。
  • 购物关系：真实商品信息和候选清单必须对应当前衣款，再验收 C19；图片生成成功不算购物联动完成。
  • 商业使用条件：取得人物与商品素材授权，替换有非商业限制的研究素材及组件，再评估上线。

AI 换装预览 · 这次验证什么

目标是把真实人物照片和服装照片送入我们本机运行的模型，得到可以复查的生成上身外观预览。“真实”指输入照片来自实拍；输出是 AI 生成图片，不是真人实际穿着、布料物理模拟或尺码验证。现有三维拖放与状态能力继续作为独立搭配入口。

  1. 照片输入：记录来源、商品照片形式，上传文件只送本机服务。
  2. 真实推理：记录输入哈希、模型、参数、设备、耗时及输出；失败明确反馈。
  3. 效果对照：拖动原图/生成图分界，放大看脸、体型、领袖、图案与遮挡。
  4. 实拍依据：有同人同衣实拍才进行真实穿着对照；缺失时明确标注。
  5. 人工评审：保留问题样例与评分，生成成功不等于效果通过。

这是C17使用场景深化，不增加第37项研究能力，也不把C19购物联动提前算作完成。自部署采用现有模型权重，不能称为从零训练或自研全部算法。

选择照片时文件只在浏览器中。按“开始试穿”后，本机服务会在此项目的本机任务目录保留输入、参数与结果，不会自动删除；没有外部试穿 API 上传。请按研究用途使用本页。

原图、参考实拍、模型生成图有不同标签。公开研究照片和人物解析组件存在研究用途限制，商业上线需要替换或取得相应授权。
