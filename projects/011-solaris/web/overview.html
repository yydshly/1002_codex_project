02 / TWO IMPLEMENTATION PATHS

来源、机制与我们的实现。

相似的鼠标体验，可以由不同系统产生。把可见效果、内部方法和已验证结果分别看清。

研究来源

Solaris：生成式界面

公开方法将点击、拖动等历史输入与视觉上下文作为后续帧的条件，由语言模型解释意图、形成场景行为提示，再自回归生成交互画面。论文还介绍少步蒸馏与在自身生成输出上训练。

核心是视觉环境直接响应操作：改变一个对象时，后续画面的背景、遮挡、材质和光照也可能变化；同一手势由上下文决定含义，对象还可成为工具来源。36 项是我们对公开材料的研究拆分，既含示例也含文字与展望。

  1. 画面与鼠标输入
  2. 意图与行为提示
  3. 生成后续画面
  4. 继续交互

Solaris 是公开研究来源，本项目尚未确认专用开源库或可调用原模型。这是根据公开资料做的简化理解；每次鼠标移动的实际调用频率及未公开内部模块仍未知。官方目前提供 early-access 申请，本项目未接入或实测 Solaris；官方录像不证明持久对象 ID、精确三维结构、真实物理或商业流程。

INPUT → MEANING → RESPONSE

核心是“输入如何产生有意义的响应”。

鼠标是输入设备。值得研究的是：系统知道作用对象是什么，如何解释连续动作，如何让关联对象响应，并在结束后保留可用成果。只出现鼠标指针或动画，还不足以说明这些能力。

同一拖动，不同工具

影像里拖动可以平移画面，也可以确定测量端点。我们的产品显式选择工具；源研究展示语言与上下文定义语义。

一个对象，关联响应

价值：用户知道正在改什么，操作错误能恢复，成果能继续使用。

B / 锦上添花

让结果更易观察

高质量素材、PBR/HDR、阴影、骨架表现、预设观察、路线/读数提示和比较画面。

价值：帮助理解变化与比较成果；漂亮画面本身不增加已验证能力。

把单次操作接成流程

对象与许可注册、项目协议、备份/选择恢复、任务往返、多窗口冲突、异常和性能。

价值：作品与工作流持续可用。真实商品、库存、价格、订单与授权仍需接入。

面对新的输入与对象

跨独立模型的支撑关系、条件性柜架扩展、未知视角/任意照片/真实适配等研究。

价值：检验规则能否推广；新对象与拒绝样本需独立验证，不能靠改参数充当突破。
